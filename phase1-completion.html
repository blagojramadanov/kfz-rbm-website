🎯 Quick Start Guide

1. Configure Supabase

Update .env.local with your Supabase credentials from https://supabase.com:

NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key SUPABASE_SERVICE_ROLE_KEY=your-service-role-key

2. Create Database Schema

Run the SQL from supabase/migrations/01_init_schema.sql in Supabase SQL Editor

3. Run Development Server

npm run dev

Visit http://localhost:3000

4. Build for Production

npm run build && npm start
